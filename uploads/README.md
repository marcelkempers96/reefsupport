# Uploads

Drop files here and Claude will move them into the site. Nothing in this folder is published as-is.

| Folder | Put here | Notes |
| --- | --- | --- |
| `hero-video/` | Home page hero clip | MP4, 10 to 20 s, 1920×1080, under 5 MB if possible (larger is fine, it will be compressed). Reef or Coral Lab footage, slow movement, no on-screen text. Add a line with the photographer or source for the credit. |
| `logo/` | Logo files | SVG preferred, otherwise a large PNG on a transparent background. |
| `photos/` | Field and project photos | JPG or PNG, as large as you have. Name them after the project (e.g. `coral-lab-lombok-01.jpg`) and add the photographer in `photos/credits.txt`. |
| `blog-posts/` | Old blog posts for Insights | Paste each post as a `.md` or `.txt` file with the title, date and author at the top, or save the web page as PDF. |
| `documents/` | Anything else | Policies, links, confirmations from `CLAUDE.md` open items. |

## How to upload on GitHub

1. Open the repository on GitHub and switch to the branch `claude/gallant-archimedes-2ikih8`.
2. Open the `uploads` folder, then the right subfolder.
3. Click **Add file → Upload files**, drag the files in, and click **Commit changes**.

GitHub's web upload accepts files up to 25 MB each.
